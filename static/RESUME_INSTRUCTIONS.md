# Resume Upload Instructions

To display your resume on the website:

1. Place your resume PDF file in this directory (`/vercel/sandbox/static/`)
2. Name it exactly: `resume.pdf`
3. The resume will automatically be available at: `/resume`

## Example:
```
/vercel/sandbox/static/resume.pdf
```

Once uploaded, visitors can:
- View the resume directly in their browser
- Download the resume as a PDF file

The resume page will automatically detect if the PDF exists and display it accordingly.
